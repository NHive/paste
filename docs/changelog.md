# 近期更新

## v2.17.2 - 2025-08-24 - 最新版本
- ✨ 新增三方登录支持：微信登录和Apple登录功能
- ✨ 用户信息同步：支持三方登录时的用户信息更新事件
- 🐛 取消登录窗口透明效果，修复快捷键显示样式问题
- 🎨 优化整体界面样式和交互体验

- ✨ 新增文件下载功能：支持主动下载文件到本地

- 🔍 搜索功能升级：优化搜索逻辑和触发机制
- 🐛 修复异常字节导致崩溃、钉钉图片复制等多项稳定性问题
