# 高级功能

本章节介绍 Paste 的一系列高级功能，帮助您提升效率、加强控制、保障隐私，从而发挥更强大的剪贴板管理能力。

## 数据预览与详情

在主窗口中选中某条记录后，按下 `空格键（Spacebar）` 可查看该记录详情：

- **文本/代码**：完整显示内容，支持语法高亮。
- **图片**：显示预览图。
- **文件**：显示名称、大小、类型等信息。
- **特定格式**：
  - `JSON`：自动格式化并高亮展示。
  - `SVG`：直接渲染为图像。
  - `HTML / RTF`：尝试展示富文本内容。

无需粘贴即可预览复杂内容，提高操作效率。

## 划词翻译与剪贴板翻译

内置多种翻译方式，快速获取内容含义：

- **划词翻译**：在任意程序中选中词句，按 `Alt + D`（默认，可自定义）即时弹出翻译窗口。
- **记录翻译**：在主窗口中选中一条文本记录，按下 `T` 键进行翻译。

::: tip 隐私提示
翻译内容通过 HTTPS 加密协议发送至第三方翻译服务（如 Google、DeepL 等），仅您主动触发的翻译操作才会发送数据。
:::

## 跨设备实时同步

只需登录同一账号，便可实现以下同步体验：

- **自动同步**：在设备 A 复制，在设备 B 即时可粘贴，支持文本、图片、文件等。
- **离线同步机制**：
  - 离线时内容本地保存。
  - 网络恢复后自动上传并拉取最新数据，实现数据一致性。

## 设备管理中心

在设置中进入 `账户与同步 -> 设备管理` 可查看和管理所有设备：

- 查看设备名、操作系统、在线状态。
- 支持远程登出丢失或异常设备。
- 可重命名设备，方便识别。

## 数据安全与加密

我们将安全作为核心设计原则：

- **本地加密**：设备中的剪贴板记录默认加密存储。
- **云端加密**：所有同步数据在服务器端加密保存。
- **传输加密**：客户端与服务器间通信全程采用 SSL/TLS 加密，确保数据传输安全。

## 文件同步控制

支持对文件同步进行高级配置：

- **容量监控**：查看云端空间使用情况。
- **大小限制**：限制自动同步的文件大小（如 100MB 以内）。
- **文件类型过滤**：（即将支持）选择是否同步某些类型文件。
- **手动清理**：可定期清理历史文件释放空间。

## 快捷键自定义

进入 `设置 -> 快捷键` 即可定制您的工作流：

- **全局操作快捷键**：
  - 唤起主窗口（默认 `Alt + V`）。
  - 快速粘贴、搜索等操作。
- **窗口内操作**：
  - 复制、删除、固定记录等功能均可设置快捷键。

## 个性化界面与主题

Paste 支持丰富的界面自定义选项：

- **主题模式**：
  - 跟随系统。
  - 始终亮色 / 暗色。
- **外观调整**：
  - 窗口透明度。
  - 主色调。
  - 列表字体大小等。

## 隐私过滤与内容排除

进一步控制哪些内容被记录或同步：

- **敏感词过滤**：设置关键词，包含该关键词的内容不会上传同步（但可保留本地）。
- **应用程序排除**：（即将支持）来自特定应用的内容不被记录。

## 高级搜索功能

快速定位历史剪贴板记录：

- 按内容类型筛选（文本 / 图片 / 文件）。
- 支持按时间范围筛选。
- 支持 `正则表达式` 查询。
- 保存搜索历史，方便下次使用。

::: tip 建议
大部分功能可在“设置”中自由启用或调整，请花些时间探索，找到最适合您的使用方式。
:::

::: warning 注意
跨设备同步、设备管理、云端存储等功能需要登录账号，并保持网络连接。
:::
