# 常见问题

> 本文整理了用户在使用 Paste 过程中的常见问题与解决方法，建议使用页面右侧目录快速定位，或按 `Ctrl+F` 搜索关键字。

## 基础使用

### 如何启动 Paste？

Paste 安装完成后会自动在后台运行，您可以通过以下方式打开主界面：

- **Windows**：按下 `Alt + V` 快捷键（默认）
- **macOS**：按下 `Option + V` 快捷键
- 或点击系统托盘（Windows）或菜单栏（macOS）图标

### 为什么复制的内容有时没有进入 Paste？

常见原因如下：

- Paste 未运行，或未开启剪贴板监听功能
- 被“忽略规则”或“隐私模式”过滤
- 系统权限不足（macOS 需开启辅助功能权限）
- 内容体积或格式异常，超出处理范围

### 为什么复制内容未同步到其他设备？

可能原因：

- 网络连接不稳定
- 未登录 Paste 账号，或账号不一致
- 同步功能未开启
- 内容大小超出限制（可在设置中调整）
- 被关键词过滤规则屏蔽
- 服务端临时故障（可稍后重试）

### 如何管理同步设备？

1. 打开 **设置**
2. 进入 **“设备管理”** 标签页
3. 查看设备列表，支持设备重命名与解除绑定

## 功能使用

### 如何收藏常用的剪贴板内容？

1. 在历史记录中找到要收藏的项目
2. 悬停后点击 **星形图标** 或“收藏”按钮
3. 收藏内容将出现在 **收藏** 分类中

### 为什么部分图片无法预览或同步？

常见原因：

- 图片过大（超出同步限制）
- 图片格式异常（如非标准编码）
- 网络不稳定
- 云端存储空间不足（非会员可能有限制）

## 性能优化

### Paste 占用较高内存或卡顿怎么办？

建议操作：

1. 减少历史记录数量或保留时间（设置中调整）
2. 清理历史记录（手动或启用自动清理）
3. 关闭不常用功能（如 OCR、划词翻译）
4. 升级至最新版本（查看更新日志）
5. 重启 Paste 或系统尝试释放资源

### 如何提升跨设备同步速度？

优化建议：

- 使用稳定高速网络（推荐 Wi-Fi 或有线）
- 设置中调整同步大小上限
- 关闭非必要同步内容（如文件）
- 选择地理位置更近的同步节点（如支持）
- 避开高峰期同步大文件
- 关闭其他耗网应用（如 BT 下载）

## 系统兼容与数据安全

### 支持哪些操作系统？

Paste 当前支持：

- **Windows**：Windows 10 及以上
- **macOS**：macOS 10.15 及以上

### 我的数据安全吗？

Paste 重视用户隐私与数据安全，保障措施包括：

- **传输加密**（SSL/TLS）
- **本地数据加密**
- **敏感内容隐私过滤**
- **云端数据安全保障**
- **远程登出设备**

### 如何备份 Paste 数据？

Paste 支持云端自动备份：

- 登录账号后，历史记录将自动加密同步至云端
- 更换设备后登录同一账号可恢复历史数据
- 无需额外备份步骤
