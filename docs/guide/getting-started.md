# 快速开始

欢迎使用 Paste！本指南将帮助您完成安装与初始配置，让您快速上手高效的剪贴板管理体验。

## 安装 Paste

### 1. 下载应用程序

请根据您的操作系统前往下载页面获取最新版安装包：

<a href="/download.html" class="VPButton vp-button_brand">前往下载页面</a>

### 2. 系统要求

确保您的设备符合以下最低系统要求：

- **Windows：** Windows 10 及以上
- **macOS：** macOS 12.0 及以上
- **网络环境：** 需要互联网连接以启用账户登录与多设备同步功能

### 3. 安装流程

- **Windows：** 双击 `Paste-Setup.exe`，按照安装向导提示完成安装
- **macOS：** 双击 `Paste.dmg`，将 Paste 图标拖拽至“应用程序”文件夹中

---

## 初始配置

### 1. 启动应用

- **Windows：** 可在「开始菜单」或桌面快捷方式中启动 Paste，运行后图标将显示于系统托盘区
- **macOS：** 可在「应用程序」中启动，图标将显示于系统菜单栏

### 2. 登录账号（推荐）

登录账号可启用同步和云备份功能：

1. 点击托盘（Windows）或菜单栏（macOS）中的 Paste 图标，打开主界面
2. 点击界面右上角的「登录 / 注册」按钮
3. 输入邮箱注册账号或直接登录已有账号
4. 登录成功后，即可在多台设备间同步剪贴内容

### 3. 基础设置（可选）

您可以根据偏好自定义以下选项：

- **开机自启：** 启动系统时自动运行 Paste
- **全局快捷键：** 自定义快捷键唤起主界面（默认 `Alt + V` / `Option + V`）
- **外观主题：** 选择亮色、暗色或跟随系统
- **界面语言：** 支持中、英等多语言切换
- **同步内容：** 设定是否同步图片、文件、文本等内容（需登录）
- **历史记录：** 控制记录保留条数与时间

## 快速上手

### 复制内容

如常使用 `Ctrl + C`（Windows）/ `Command + C`（macOS）复制文本、图片或文件，Paste 将自动捕获并记录。

### 查看与粘贴内容

1. 按下全局快捷键（默认 `Alt + V` / `Option + V`）唤出 Paste 主界面
2. 查看按时间倒序排列的历史记录
3. 粘贴方式：
    - **双击** 内容：直接粘贴到当前应用
    - **↑ / ↓ 键选择** + **Enter 键确认**
    - **右键点击** 可查看更多操作（复制、收藏、删除等）

### 同步使用说明

登录后：

- 剪贴内容将在您的所有设备间同步显示
- 在「设置 → 同步选项」中可配置同步类型、文件大小限制等规则
