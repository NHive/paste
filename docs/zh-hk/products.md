# 為日常工作做的幾款軟件

從裝置協同到文件掃描、收據整理，這幾款軟件分別解決日常工作中的不同問題。

## ArcRelay：讓自己的裝置協同工作

ArcRelay 延續了 Paste 的開發方向，是一款開源、區域網絡優先的跨裝置應用，用於在可信裝置之間接力剪貼簿內容、檔案和輸入。適合需要在自己控制的網絡中使用多台電腦的場景。

[了解 ArcRelay 並查看官方下載](https://arcrelay.app/zh/products/arcrelay#downloads)。Paste 用戶可以閱讀[遷移說明](/zh-hk/download)及[舊版指南](/zh-hk/guide/getting-started)。Paste 已停止維護，目前尚未確認帳號、訂閱和歷史記錄可以自動遷移。

## StarScan：把紙張變成清晰的電子文件

StarScan 面向全球用戶，提供無廣告、無水印的文件掃描體驗，專注文件掃描、文字識別和 PDF 整理。適合筆記、合約和日常資料等需要留存清晰電子副本的場景。

[了解 StarScan 文件掃描](https://starscanapp.com/)。各平台目前是否可以下載，請查看官網的下載區域。

## Stareceipt：整理收據和支出記錄

Stareceipt 專注收據整理，服務加拿大、美國及其他支援市場的用戶。它面向需要保留購買憑據、整理收據和支出記錄的人，而一般資料掃描可以選擇 StarScan。

[了解 Stareceipt 收據整理](https://www.stareceipt.com/zh-Hant)。功能、支援市場和目前方案以 Stareceipt 官網為準。
